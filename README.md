# unit-7-words

Одностраничный тренажёр слов для Unit 7 (7.1 Vocabulary, 7.2 Grammar, 7.3 Listening, word families).
Карточки, свайпы, фильтры, поиск, режим теста и заметки по грамматике. Прогресс хранится в localStorage.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Собранный сайт лежит в `dist/` и не требует бэкенда: его можно положить на любой статический хостинг.

## Управление

- тап по карточке — перевернуть
- свайп влево / вправо, стрелки `←` `→` — листать
- свайп вверх / `↑` — «знаю», свайп вниз / `↓` — «не знаю»
- `пробел` — перевернуть, в режиме теста — показать ответ
